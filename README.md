# 知食 / NutriMadam

[中文](./README.md) | [English](./README.en.md)

一款纯原生实现的营养追踪微信小程序（WXML / WXSS / JS），**零框架、零 npm 依赖、零构建步骤**，所有数据均保存在本地 `wx.storage`。

## 核心功能

- **身体档案与每日目标（我的）**
  - 基于 Mifflin-St Jeor 公式计算基础代谢率（BMR）与每日总消耗（TDEE），按「减脂 / 维持 / 增肌」目标分配热量与宏量营养素；
  - 对小基数人群（`TDEE < 1200 kcal`）减脂场景做安全上限保护，确保目标热量不超过每日消耗；
  - 依据《中国居民膳食营养素参考摄入量（DRIs）》按性别与年龄段给出维生素 A、钙、镁、铁、锌等微量营养素参考目标。
- **食物搜索与饮食记录（记录）**
  - 内置 1,676 条《中国食物成分表标准版（第 6 版）》数据；
  - 支持常见口语同义词（如 `鸡胸肉`、`牛油果`、`水煮蛋`、`白米饭`、`圣女果`、`奇异果`）、全/半角括号归一化及空格多词分词检索；
  - 记录弹窗支持克数快捷标签与**实时热量/宏量营养预览**，支持补记历史日期并在切后台返回时保留补记上下文。
- **今日总览与分时段营养建议（今日）**
  - 追踪每日热量、4 项宏量营养素（蛋白质、碳水、脂肪、膳食纤维）及 6 项微量营养素（维 A、维 C、钙、镁、铁、锌），提供热量与宏量超标视觉提醒；
  - 支持翻阅历史日期、补记与删除记录；
  - 运行时**无任何 LLM 调用**：内置开发期固化的分时段静态文案库（覆盖全部 10 项营养素）与食物标签安全过滤引擎，自动剔除野生有毒/非日常/高脂内脏及深加工条目，给出可点击直达记录的推荐食材与健康小习惯。

## 快速开始

### 1. 在微信开发者工具中运行
1. 打开 **微信开发者工具**，选择「导入项目」；
2. 项目目录选择本仓库根目录（`project.config.json` 已配置 `miniprogramRoot: "miniprogram/"`）；
3. 导入后点击「编译」即可预览；如需重置本地调试数据，可点击顶部菜单 **清缓存 → 清除数据缓存**。

### 2. 运行自动化测试（Node.js）
无需打开微信开发者工具，在仓库根目录直接运行（推荐 Node.js 18+）：

```bash
# 运行全部测试（工具单测 + 端到端回归，共 188 条）
node --test tests/utils.test.js tests/e2e.test.js

# 单独运行工具与回归单测
node --test tests/utils.test.js

# 单独运行端到端测试套件
node --test tests/e2e.test.js
```

## 数据来源与免责声明

- 食物营养成分数据整理自《中国食物成分表标准版（第 6 版）》（参考 [china-food-composition-data](https://github.com/Sanotsu/china-food-composition-data)），并补充修正了缺失热量字段；
- 本小程序仅用于个人日常饮食记录与一般营养参考，不构成任何医疗诊断或临床营养处方。
